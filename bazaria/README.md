# BAZARIA | بازاریا

بازار چندفروشندگی افغانستان؛ رابط دری/فارسی راست‌به‌چپ، افغانی و طراحی موبایل‌محور.

## وضعیت نسخه
این شاخه شامل MVP فرانت‌اند و migration اولیه Supabase است. امکانات دمو: جست‌وجو و فیلتر کالا، سبد خرید، ثبت سفارش COD، درخواست فروشندگی، افزودن کالای آزمایشی، نمایش سفارش‌ها و پوسته PWA برای cache آفلاین.

**محدودیت‌ها:** احراز هویت واقعی، پایگاه داده متصل، پنل امن نقش‌محور، همگام‌سازی چنددستگاهی، درگاه پرداخت، اتصال شرکت حمل‌ونقل، اعلان پیامکی، تست امنیتی/عملیاتی و استقرار عمومی هنوز انجام نشده‌اند. فرم‌ها و تأیید فروشنده در UI فقط محلی و نمایشی‌اند. localStorage بین دستگاه‌ها/کاربران مشترک نیست و برای داده حساس یا فروش واقعی مناسب نیست.

## اجرای سریع
پوشه bazaria را روی یک میزبان استاتیک اجرا کنید. برای Service Worker و نصب PWA به HTTPS یا localhost نیاز است؛ بازکردن file:// کافی نیست.

## فایل‌ها
- index.html: صفحه فروشگاه
- styles.css: طراحی واکنش‌گرا
- app.js: منطق دموی محلی
- manifest.webmanifest / sw.js / icon.svg: نصب‌پذیری و cache پوسته
- supabase/schema.sql: طرح اولیه دیتابیس و RLS

## آماده‌سازی بک‌اند
schema.sql را فقط در یک پروژه Supabase تازه و پس از بازبینی اجرا کنید. نقش مدیر باید فقط از مسیر مورد اعتماد تعیین شود. هرگز service_role key را در مرورگر یا GitHub قرار ندهید. سیاست‌های RLS باید پیش از انتشار با حساب‌های جداگانه مشتری، فروشنده و مدیر آزمایش شوند.

1. ایجاد و ارزیابی دسترسی/هزینه سرویس‌ها در افغانستان

5. تعیین مناطق تحویل، کرایه، مرجوعی و روش پرداخت واقعی
